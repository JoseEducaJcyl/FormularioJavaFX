# FormularioJavaFX

Proyecto desarrollado en Java utilizando JavaFX y Maven para la creación de formularios e interfaces gráficas de usuario.

## Descripción

La aplicación consiste en un formulario gráfico creado con JavaFX, permitiendo trabajar con distintos controles visuales como campos de texto, botones y otros componentes de entrada de datos.

El proyecto está orientado a la práctica de diseño de formularios y gestión básica de eventos en aplicaciones de escritorio Java.

## Tecnologías utilizadas

- Java
- JavaFX
- Maven

## Requisitos

- JDK 17 o superior
- Maven instalado
- IDE compatible con JavaFX
